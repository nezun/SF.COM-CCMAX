# Miran San / SleepFoundation Benchmark System

This repository contains a local benchmark and execution blueprint for building `miransan.org` as a Serbian sleep authority and content-commerce property inspired by SleepFoundation.org's system, not its protected expression.

## What exists now

- `npm run sf:benchmark` builds a SleepFoundation source-of-truth JSON and HTML report.
- `npm run sf:parity` scores Miran San's planned system against the benchmark and outputs a parity audit.
- `docs/sleepfoundation-business-blueprint.md` contains the Phase 1 strategic reverse-engineering blueprint.
- `docs/serbia-translation-blueprint.md` contains the Serbia/Adria market translation and launch IA.
- `content/data/miransan-page-templates.json` defines reusable page templates for SEO, CRO, EEAT, schema, and compliance.
- `content/data/miransan-url-plan.json` contains the first 150 planned URLs with priority, intent, template, monetization angle, and review status.

## Commands

```bash
npm run sf:benchmark
npm run sf:parity
npm run validate
```

## Confidence protocol

All major findings in strategy artifacts should use:

- `[VERIFIED]` for repo evidence, benchmark artifacts, live-site observation, or checked source evidence.
- `[HIGH-CONFIDENCE INFERENCE]` for strong pattern-based inference.
- `[HYPOTHESIS]` for working assumptions.
- `[UNKNOWN / NEEDS VALIDATION]` where evidence is insufficient.

## Legal boundary

We copy the system architecture, not SleepFoundation's text, design, images, doctors, reviewers, sources, proprietary tests, brand identity, or medical/product claims.
